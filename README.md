# 면접 한 걸음 · CX Interview Lite

스냅컴퍼니 AI 솔루션 AM팀 면접을 준비하는 가벼운 웹앱입니다. 기존 CX Interview Lab과 별도 저장소·저장 키로 운영됩니다.

- 컬처핏 36개 + 직무 30개, 본 질문 66개와 꼬리질문 129개
- 한 화면에 질문 하나, 질문과 참고 답변 바로 표시
- 이전·다음 이동, 꼬리질문과 참고 답변 확인, 다시 볼 질문 표시
- 전체 질문 목록과 질문·답변 검색
- 전체/컬처핏/직무/중요/다시 보기 범위, 순서대로 또는 중복 없는 무작위 연습
- 모바일 대응, 외부 라이브러리·서버·유료 API 없음

## 사용

`index.html`을 열거나 정적 웹 서버로 실행합니다. 예: `python3 -m http.server 8000` 후 http://localhost:8000 접속.

학습 준비 → 질문과 참고 답변 읽기 → 꼬리질문 확인 → 읽었어요·다음. 다음 버튼으로 읽은 질문을 기록합니다. 답변 입력칸은 없습니다. 질문을 건너뛰려면 전체 질문 목록에서 원하는 질문을 선택하세요.

기록은 현재 브라우저의 localStorage `cx-interview-lite:snapcompany:v1`에 저장됩니다. 기기 간 동기화되지 않습니다. 브라우저 데이터를 지우면 기록이 사라집니다. 읽음·다시 보기 표시를 저장하지 못하면 안내합니다. 예전에 작성한 답변 데이터가 있더라도 삭제하지 않습니다.

## 자료

`questions.js`: 사용자 제공 스냅컴퍼니 원문 질문·참고 답변·꼬리질문·주의 문구·부록. 기존 앱의 자료를 그대로 복사했습니다. 실제 출제·합격자 답변이 아니며 개인의 실제 경험을 확인하면서 사용하세요. 일반 학습 화면에 편집·기업 관리 등 복잡한 기능은 두지 않았습니다.

`index.html`: 화면 / `styles.css`: 디자인 / `app.js`: 연습과 저장.

## 검증

`tests/smoke.cjs`는 Playwright와 Chromium이 설치된 개발 환경에서 `node tests/smoke.cjs`로 실행합니다. 앱 자체에는 Node나 빌드 도구가 필요하지 않습니다.

## 질문 추가와 답변 수정

상단 **전체 질문** → **새 질문 추가**에서 컬처핏/직무 유형, 질문, 참고 답변을 입력하고 저장하세요. 꼬리질문도 원하는 만큼 추가할 수 있습니다. 기존 질문을 펼친 뒤 **질문·답변 수정**을 누르면 본 질문, 참고 답변, 꼬리질문과 답변을 수정할 수 있습니다.

개인 편집본은 같은 localStorage 안의 `customQuestions`에 저장하고 원본 파일과 기존 읽음·다시 보기 기록은 보존합니다. 이 브라우저에서만 적용되며 다른 기기나 GitHub 원본에 자동 반영되지 않습니다. 브라우저 데이터를 삭제하면 개인 편집본도 사라집니다. 저장 실패 시 편집창의 입력은 유지됩니다.

연습 중에도 참고 답변 옆 **답변 수정** 버튼으로 현재 질문과 답변을 수정할 수 있습니다. 꼬리질문에서 열면 해당 꼬리질문의 답변으로 바로 이동합니다. 저장하면 연습 순서·진행률을 유지한 채 화면에 즉시 반영됩니다.

우측 상단 ↻ 버튼은 최신 HTML·CSS·JavaScript를 새 주소로 요청합니다. 저장된 개인 질문과 수정 답변·읽음 기록은 유지되고 현재 연습 세션은 학습 준비 화면으로 돌아갑니다. 저장하지 않은 편집은 확인 후 닫습니다.
